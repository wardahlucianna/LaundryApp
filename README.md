# Sunrise Laundry — UI Preview

Prototype React + TypeScript untuk halaman Akses & Hak Akses:
- Manajemen Role
- Manajemen Pengguna
- Manajemen Fitur/Menu
- Pengaturan Hak Akses

## Menjalankan lokal
```bash
npm install
npm run dev
```

Prototype ini masih memakai data contoh di browser, belum terhubung ke Laravel API atau PostgreSQL. Database yang direncanakan: `laundyDb`.
